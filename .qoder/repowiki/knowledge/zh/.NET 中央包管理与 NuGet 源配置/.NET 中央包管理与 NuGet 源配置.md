本仓库采用 .NET 10/11 的中央包版本管理（Central Package Management）策略，通过 MSBuild 全局属性与单一清单文件统一管理所有第三方依赖的版本号，避免各子项目重复声明版本导致的不一致问题。

核心机制与文件：
- Directory.Packages.props：集中定义所有 PackageVersion 条目，覆盖 EF Core、Serilog、OpenTelemetry、Dapr、WolverineFx、Polly、MassTransit、SignalR、NSwag/Swashbuckle、SkiaSharp、MessagePack、RestSharp/Refit、Quartz、OpenIddict、Nacos、Grpc、EasyCaching、StackExchange.Redis、SonarAnalyzer/Roslynator/StyleCop 等数百个 NuGet 包。部分包标记 PrivateAssets=all 或限定 IncludeAssets，仅用于编译期分析器、Source Generator 或构建任务。
- Directory.Build.props：启用 ManagePackageVersionsCentrally=true 与 CentralPackageTransitivePinningEnabled=true，强制所有子项目使用中央清单；同时定义一组公共版本号变量（如 MicrosoftExtensionsVersion、AspNetCoreVersion、OpenTelemetryVersion、WolverineFxVersion、PollyVersion、EasyCachingVersion、NSwagVersion、SwashbuckleVersion、NacosVersion、GrpcVersion、OpenIddictVersion、QuartzVersion），供子项目引用时保持一致。
- NuGet.Config：声明唯一包源为 nuget.org（https://api.nuget.org/v3/index.json），并配置了 auditSources 指向同一源；注释中保留了企业内部私有源（dotnet-eng、dotnet9-transport、dotnet-preview、内网 172.100.61.40:8081）及 packageSourceMapping 示例，当前处于禁用状态。
- global.json：锁定 SDK 版本为 11.0.100-preview.6，允许 latestMajor 回退与预发行版，支持本地 .dotnet 目录与宿主安装路径。

架构与约定：
- 所有子项目不再在 .csproj 中写死版本号，而是通过 PackageReference 引用包名，由 MSBuild 解析到 Directory.Packages.props 中的统一版本。
- 对仅参与编译/分析的包（如 Roslynator、StyleCop、SonarAnalyzer、NSwag.Generation.AspNetCore、Mediator.SourceGenerator、Jab、MinVer 等）统一设置 PrivateAssets=all 且限定 IncludeAssets，避免污染运行时依赖。
- 通过 common.props 与 Directory.Build.props 提供跨项目的通用构建属性（LangVersion、NoWarn、Razor 冲突抑制等），保证风格与警告策略一致。

约束与规则：
- 禁止在子项目 .csproj 中直接指定包版本，必须依赖中央清单（由 ManagePackageVersionsCentrally 强制）。
- 包源默认仅允许 nuget.org，如需引入私有源需显式修改 NuGet.Config 并取消相应注释。
- 分析器/工具类包必须标记 PrivateAssets=all 且限定 IncludeAssets，确保不进入最终输出。
- SDK 版本由 global.json 锁定，要求运行环境具备匹配的 .NET SDK 或通过 ./install.sh 安装。
