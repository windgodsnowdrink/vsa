项目采用单文件脚本化 C#（Top-level statements + `#:sdk`/`#:package` 指令）组织，以 `IoT.cs` 为应用入口，通过 `WebApplication.CreateBuilder` 构建 ASP.NET Core 主机，注册 Razor Components、OpenAPI、Hybrid/StackExchange Redis 缓存等中间件，并由 `App.razor` / `pages/Index.razor` 提供 Blazor 前端页面。

- 驱动层：每个协议对应一个独立 `.cs` 文件（Modbus.cs、Siemens.cs、Omron.cs、Fatek.cs、Keyence.cs、BACnet.cs、OpcUa.cs、OpcDa.cs、MQTT.cs、Redis.cs、RocketMQ.cs、LoRa.cs、NetPing.cs 等），均实现统一的 `DriverBase`/`AsyncDriverBase` 抽象，并通过 `[Driver("...")]` 特性标注驱动名称，由反射自动发现注册。
- 通用驱动：`IoT.cs` 内集中实现了 IoTDatabaseDriver（SQL 数据源）、IoTSerialDriver（串口）、IoTHttpDriver/IoTSocketDriver（TCP/UDP/HTTP）等通用驱动，遵循相同的参数类+节点类+驱动类三件套模式。
- 原生库：`nativelib/` 使用 CMake 构建 C++ 共享库 `greetings`，包含 LoRa MAC 加解密、AES、CMAC 等算法，供上层 C# 通过 P/Invoke 调用。
- 依赖方向：C# 驱动 → Feature.* 内部命名空间（Data、IoT、Serialization、Reflection 等）→ 可选 native lib；Blazor 前端仅通过 HTTP 与后端交互。
- 运行配置：`IoT.run.json` 定义 http/https 双端点调试 profile，`Iot.settings.json` 提供运行时配置，`nuget.config` 指定包源。
