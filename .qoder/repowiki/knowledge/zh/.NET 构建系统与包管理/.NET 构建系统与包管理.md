该仓库采用基于 MSBuild 的 .NET 构建系统，通过全局属性文件集中管理所有项目的构建配置、包版本和代码分析规则，形成统一的跨项目构建一致性。

## 构建系统架构

核心构建文件包括 Directory.Build.props（根级 MSBuild 属性定义，包含目标框架 net11.0、语言版本 preview、隐式 using、可空引用类型、SonarQube 集成等）、Directory.Build.targets（统一生成 XML 文档文件）、Directory.Packages.props（集中式包版本管理，统一管理 593 个 NuGet 包的版本）、global.json（锁定 .NET SDK 版本为 11.0.100-preview.6）和 build.cake（Cake Build 脚本，提供 Clean、Restore、Build、Test、Publish、DockerBuild 等任务）。

## 包管理与依赖控制

启用 ManagePackageVersionsCentrally 和 CentralPackageTransitivePinningEnabled，所有包版本在 Directory.Packages.props 中统一定义。使用 MinVer 进行语义化版本管理，版本号从 Git 标签自动生成。NuGet.Config 配置 NuGet 源，默认指向 nuget.org。

## 代码质量与静态分析

StyleCop 进行代码风格检查，Roslynator 增强 Roslyn 分析器，SonarQube 进行代码质量分析。编译选项启用 Nullable 引用类型检查、强制代码样式检查、生成 XML 文档文件，并将特定警告作为错误处理。

## 容器化与发布

Cake 脚本中的 DockerBuild 任务自动发现所有 Dockerfile，支持多平台交叉编译（buildx），自动注入 Git 提交哈希和版本号到镜像标签。构建产物输出到 artifacts 目录，包含测试覆盖率报告和 TRX/HTML 格式的测试结果。

## 环境配置

支持 Debug/Release/Staging/Production 四种构建配置，自动根据配置推断 Environment 常量，条件编译符号包括 DEBUG、Android、iOS、Windows、Mac 等。
