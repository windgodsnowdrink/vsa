# Jieba 中文分词工具

## 技能简介

Jieba 技能是基于 jieba.NET 库开发的 AOT 编译中文分词工具，提供高效、准确的中文文本处理能力。该工具采用 .NET 10.0 框架，通过 AOT（Ahead-of-Time）编译技术，实现了高性能的中文分词、关键词提取、词性标注等功能。

### 主要特点

- **AOT 编译**：采用 .NET 10.0 AOT 编译技术，启动速度快，运行效率高
- **多模式分词**：支持精确模式、全模式、搜索引擎模式三种分词模式
- **关键词提取**：基于 TF-IDF 算法的关键词提取功能
- **词性标注**：支持中文词性标注
- **批量处理**：支持文本文件的批量处理
- **性能测试**：内置性能基准测试功能
- **跨平台**：支持 Windows、Linux、macOS 等多个平台

## 技术架构

### 核心组件

- **jieba.NET**：提供核心的中文分词算法

## 安装和配置

### 系统要求

- **操作系统**：Windows 10/11、Linux、macOS
- **框架**：.NET 10.0 或更高版本（AOT 编译版本为自包含，无需安装 .NET 运行时）
- **内存**：至少 64MB，推荐 512MB 以上
- **磁盘空间**：至少 100MB

### 配置选项

通过环境变量进行配置：

| 环境变量 | 描述 | 默认值 |
|---------|------|--------|
| `JIEBA_DICT_PATH` | 自定义词典路径 | 空（使用内置词典） |
| `JIEBA_HMM_PATH` | HMM 模型路径 | 空（使用内置模型） |
| `JIEBA_USER_DICT_PATH` | 用户自定义词典路径 | 空 |
| `JIEBA_BATCH_SIZE` | 批量处理大小 | 100 |
| `JIEBA_BENCHMARK_ITERATIONS` | 基准测试迭代次数 | 10000 |

## 使用方法

### 基本使用

```bash
# 精确模式分词
jieba_aot cut 这是一个测试文本

# 全模式分词
jieba_aot cutall 这是一个测试文本

# 搜索引擎模式分词
jieba_aot cutforsearch 这是一个测试文本

# 提取关键词
jieba_aot extract 这是一个测试文本，用于测试关键词提取功能

# 词性标注
jieba_aot pos 这是一个测试文本

# 批量处理文本文件
jieba_aot batch input.txt output.txt

# 运行性能基准测试
jieba_aot benchmark

# 显示帮助信息
jieba_aot help
```

### 命令别名

| 完整命令 | 别名 | 描述 |

| `extract` | `e` | 提取关键词 |

| `batch` | `b` | 批量处理文本文件 |

| `help` | `h` | 显示帮助信息 |

## 命令参考

### cut 命令

**功能**：精确模式分词，试图将句子最精确地切开，适合文本分析。

**语法**：
```bash
jieba_aot cut <text>
```

**示例**：
```bash
jieba_aot cut 这是一个测试文本
# 输出：这 是 一个 测试 文本
```

### cutall 命令

**功能**：全模式分词，把句子中所有的可以成词的词语都扫描出来，速度非常快，但是不能解决歧义。

**语法**：
```bash
jieba_aot cutall <text>
```

**示例**：
```bash
jieba_aot cutall 这是一个测试文本
# 输出：这 是 一个 测试 文本
```

### cutforsearch 命令

**功能**：搜索引擎模式分词，在精确模式的基础上，对长词再次切分，提高召回率，适合用于搜索引擎分词。

**语法**：
```bash
jieba_aot cutforsearch <text>
```

**示例**：
```bash
jieba_aot cutforsearch 这是一个测试文本
# 输出：这 是 一个 测试 文本
```

### extract 命令

**功能**：提取关键词，基于 TF-IDF 算法。

**语法**：
```bash
jieba_aot extract <text>
```

**示例**：
```bash
jieba_aot extract 这是一个测试文本，用于测试关键词提取功能
# 输出：测试 文本 关键词 提取 功能
```

### pos 命令

**功能**：词性标注，对分词结果进行词性标注。

**语法**：
```bash
jieba_aot pos <text>
```

**示例**：
```bash
jieba_aot pos 这是一个测试文本
# 输出：
# 这: r
# 是: v
# 一个: m
# 测试: v
# 文本: n
```

### batch 命令

**功能**：批量处理文本文件，对文件中的每一行进行分词处理。

**语法**：
```bash
jieba_aot batch <input_path> [output_path]
```

**参数**：
- `input_path`：输入文件路径
- `output_path`：输出文件路径（可选，默认在输入文件同目录下生成 `{input_filename}_segmented.txt`）

**示例**：
```bash
jieba_aot batch input.txt output.txt
# 处理完成后，结果保存到 output.txt
```

### benchmark 命令

**功能**：运行性能基准测试，测试各种分词模式的性能。

**语法**：
```bash
jieba_aot benchmark
```

**示例**：
```bash
jieba_aot benchmark
# 输出性能测试结果
```

### help 命令

**功能**：显示帮助信息。

**语法**：
```bash
jieba_aot help
```

## 使用场景

### 文本分析

- **情感分析**：通过分词和关键词提取，分析文本的情感倾向
- **主题识别**：识别文本的主要主题和内容
- **文本分类**：基于分词结果进行文本分类

### 搜索引擎

- **索引构建**：对网页内容进行分词，构建搜索索引
- **查询处理**：对用户查询进行分词，提高搜索准确性
- **相关度排序**：基于分词结果计算文档与查询的相关度

### 自然语言处理

- **命名实体识别**：识别文本中的命名实体
- **依存句法分析**：分析句子的句法结构
- **机器翻译**：作为机器翻译的预处理步骤

### 信息检索

- **文档检索**：基于分词结果检索相关文档
- **问答系统**：对问题和答案进行分词处理
- **信息抽取**：从文本中抽取结构化信息

## 限制和注意事项

1. **词典加载**：首次运行时需要加载词典，可能会有短暂延迟
2. **内存占用**：处理大文本时，内存占用会增加，建议根据实际情况调整内存限制
3. **自定义词典**：自定义词典支持有限，仅支持简单的词频调整
4. **性能优化**：对于大规模文本处理，建议使用批量处理模式
5. **错误处理**：输入文本为空或格式不正确时，会返回错误信息

## 常见问题

### Q: 分词结果不准确怎么办？

**A**：可以尝试以下方法：
- 使用搜索引擎模式分词，提高召回率
- 调整自定义词典，添加专业术语
- 对于特定领域的文本，考虑使用领域特定的分词模型

### Q: 处理大文件时内存不足怎么办？

**A**：可以：
- 增加内存限制
- 调整批量处理大小（通过 JIEBA_BATCH_SIZE 环境变量）
- 将大文件分割成多个小文件进行处理

### Q: 如何提高关键词提取的准确性？

**A**：可以：
- 调整关键词提取的 topN 参数
- 使用领域特定的停用词表
- 结合词性标注结果，过滤掉不需要的词性

### Q: 词性标注的标签含义是什么？

**A**：词性标注使用的是 jieba.NET 的默认标签体系，主要标签包括：
- n：名词
- v：动词
- a：形容词
- r：代词
- m：数词
- q：量词
- d：副词
- p：介词
- c：连词
- u：助词
- x：标点符号
