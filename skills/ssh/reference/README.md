# SSH 技能参考文档

## 概述

SSH 技能是一个基于 .NET 10 开发的 SSH 客户端工具包，提供了完整的 SSH 连接、命令执行、文件传输和代码生成功能。该技能采用 AOT 编译技术，确保了高性能和快速启动。

## 目录结构

```
ssh/
├── index.yaml          # 技能元数据和配置
├── SKILL.md            # 技能文档
├── scripts/            # 脚本文件
│   ├── ssh_core.cs             # 核心 SSH 功能
│   ├── ssh_core.setting.json   # 编译配置
│   ├── ssh_core.run.json       # 运行配置
│   ├── ssh_generator.cs        # 代码生成功能
│   ├── ssh_generator.setting.json  # 编译配置
│   └── ssh_generator.run.json      # 运行配置
└── reference/          # 参考文档
    ├── README.md       # 本参考文档
    └── examples.md     # 使用示例
```

## 核心功能

### 1. SSH 连接管理

- 支持密码和密钥认证
- 支持自定义端口和超时设置
- 支持连接池管理
- 支持会话保持

### 2. 命令执行

- 支持同步和异步命令执行
- 支持命令超时设置
- 支持获取命令执行结果和退出码
- 支持交互式命令执行

### 3. 文件传输

- 支持 SFTP 文件上传和下载
- 支持文件和目录操作
- 支持文件权限设置
- 支持文件传输进度监控

### 4. 代码生成

- 支持生成 SSH 配置文件
- 支持生成 SSH 脚本文件
- 支持生成批量操作脚本
- 支持模板管理

### 5. 依赖注入

- 集成 Microsoft.Extensions.DependencyInjection
- 支持 Scrutor 高级服务注册
- 支持装饰器模式实现横切关注点
- 支持服务生命周期管理

## 技术栈

- **.NET 10**: 目标框架
- **SSH.NET**: SSH 协议实现
- **Microsoft.Extensions.DependencyInjection**: 依赖注入
- **Scrutor**: 高级服务注册
- **System.CommandLine**: 命令行界面
- **System.Text.Json**: JSON 序列化

## AOT 编译

本技能采用 AOT 编译技术，配置如下：

- `PublishAot=true`: 启用 AOT 编译
- `TrimMode=partial`: 部分裁剪模式
- `SelfContained=true`: 自包含部署
- `PublishSingleFile=true`: 单文件发布

## 性能优化

1. **连接池管理**: 减少连接建立开销
2. **内存缓存**: 缓存常用配置和模板
3. **异步编程**: 采用 async/await 模式
4. **批量操作**: 支持批量命令执行和文件传输
5. **连接复用**: 支持会话保持和连接复用

## 安全性

1. **密钥管理**: 支持安全的密钥存储和使用
2. **密码保护**: 密码不会在日志中明文显示
3. **文件传输加密**: 所有文件传输均通过 SSH 加密通道
4. **权限控制**: 支持文件权限设置和验证

## 扩展性

1. **插件系统**: 支持自定义插件
2. **模板系统**: 支持自定义模板
3. **服务注册**: 支持 Scrutor 高级服务注册
4. **装饰器模式**: 支持横切关注点扩展

## 故障排除

### 常见问题

1. **连接失败**
   - 检查网络连接
   - 检查 SSH 服务器配置
   - 检查认证信息

2. **命令执行失败**
   - 检查命令语法
   - 检查用户权限
   - 检查命令超时设置

3. **文件传输失败**
   - 检查文件路径
   - 检查文件权限
   - 检查磁盘空间

4. **AOT 编译失败**
   - 检查依赖项兼容性
   - 检查裁剪设置
   - 检查 .NET 版本

### 日志记录

SSH 技能提供了详细的日志记录，可通过设置环境变量 `SSH_LOG_LEVEL` 来调整日志级别：

- `DEBUG`: 详细调试信息
- `INFO`: 一般信息
- `WARN`: 警告信息
- `ERROR`: 错误信息
