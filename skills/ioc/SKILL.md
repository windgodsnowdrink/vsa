# IOC 技能文档

## 概述

IOC 技能是一个基于 .NET 10 的高性能依赖注入容器，支持 AOT（Ahead-of-Time）编译，提供了丰富的依赖注入功能。该技能采用单文件执行模式，具有优异的性能和可靠性。

## 核心功能

### 基本功能
- **服务注册**：支持注册各种类型的服务，包括接口和实现类
- **服务解析**：根据类型或接口解析已注册的服务
- **容器构建**：构建依赖注入容器，解析服务依赖关系
- **生命周期管理**：支持 Transient、Scoped 和 Singleton 三种生命周期
- **配置管理**：提供详细的配置选项，支持自定义容器行为

### 高级功能
- **自动装配**：自动解析和注入服务依赖
- **循环依赖检测**：检测并防止循环依赖
- **基准测试**：运行性能基准测试，评估容器性能
- **日志记录**：详细的日志记录，便于调试和监控

## 技术特性

### 性能优化
- **AOT 编译**：使用 Ahead-of-Time 编译提高性能
- **单文件发布**：生成单个可执行文件，便于部署和使用
- **内存使用优化**：减少运行时内存占用
- **并发处理支持**：支持多线程并发操作
- **高性能解析**：优化服务解析算法

### 技术架构
- **模块化设计**：清晰的职责分离，便于维护和扩展
- **依赖注入**：使用依赖注入模式，提高代码可测试性
- **配置选项**：使用强类型配置选项，便于管理配置
- **错误处理**：完善的错误处理和日志记录
- **命令行界面**：友好的命令行界面，支持命令别名

## 安装与配置

### 系统要求
- .NET 10 运行时
- Windows x64 操作系统

### 安装方法
1. 确保已安装 .NET 10 运行时
2. 下载发布的单文件可执行程序
3. 直接运行即可使用

### 配置选项
配置文件位于 `ioc_aot.setting.json`，支持以下配置：

| 配置项 | 描述 | 默认值 |
|--------|------|--------|
| DefaultLifetime | 默认生命周期 | transient |
| EnableAutoWiring | 是否启用自动装配 | true |
| EnableCircularDependencyDetection | 是否启用循环依赖检测 | true |
| EnableLogging | 是否启用日志记录 | true |
| MaxRegistrationDepth | 最大注册深度 | 10 |
| EnableBenchmarking | 是否启用基准测试 | true |

### 生命周期选项

| 生命周期 | 描述 |
|----------|------|
| transient | 每次请求创建新实例 |
| scoped | 每个作用域创建一个实例 |
| singleton | 整个应用程序生命周期只创建一个实例 |

## 使用方法

### 命令格式
```bash
ioc_aot <command> [arguments]
```

### 命令列表

| 命令 | 别名 | 描述 | 参数 |
|------|------|------|------|
| register | r | 注册服务 | serviceType lifetime |
| resolve | res | 解析服务 | serviceType |
| build | b | 构建容器 | |
| config | co | 显示配置 | |
| benchmark | bm | 运行基准测试 | iterations |
| help | h, ? | 显示帮助信息 | |

### 示例

#### 1. 注册服务

```bash
ioc_aot register System.String singleton
```

**预期输出**：
```
注册服务: System.String, 生命周期: singleton
服务注册完成! 用时: 12.345 ms
```

#### 2. 解析服务

```bash
ioc_aot resolve System.String
```

**预期输出**：
```
解析服务: System.String
服务解析完成! 用时: 5.678 ms
解析结果: System.String
```

#### 3. 构建容器

```bash
ioc_aot build
```

**预期输出**：
```
构建容器...
容器构建完成! 用时: 8.901 ms
注册的服务数量: 1
```

#### 4. 显示配置

```bash
ioc_aot config
```

**预期输出**：
```
IOC 配置:
默认生命周期: transient
自动装配: True
循环依赖检测: True
日志记录: True
最大注册深度: 10
基准测试: True
```

#### 5. 运行基准测试

```bash
ioc_aot benchmark 1000
```

**预期输出**：
```
运行基准测试，迭代次数: 1000
基准测试完成! 平均解析时间: 0.123 ms
每秒操作数: 8130.08 ops/s
```

#### 6. 显示帮助信息

```bash
ioc_aot help
```

**预期输出**：
```
IOC AOT 容器 命令帮助:
============================================================
register (r)     - 注册服务
resolve (res)    - 解析服务
build (b)        - 构建容器
config (co)      - 显示配置
benchmark (bm)   - 运行基准测试
help (h, ?)      - 显示帮助信息
```

## 性能特性

### AOT 编译优势
- **启动速度快**：AOT 编译消除了 JIT 编译的开销
- **内存占用低**：减少了运行时的内存使用
- **部署简单**：单文件发布，无需额外依赖
- **安全性高**：减少了运行时攻击面

### 性能优化策略
1. **AOT 编译**：使用 Ahead-of-Time 编译提高性能
2. **内存管理**：优化内存分配和释放
3. **并发处理**：支持多线程并发操作
4. **缓存机制**：缓存已解析的服务，提高重复解析性能
5. **算法优化**：使用高效的服务解析算法

## 故障排除

### 常见问题

#### 1. 无法运行程序
- 检查是否已安装 .NET 10 运行时
- 检查操作系统是否为 Windows x64

#### 2. 服务注册失败
- 检查类型名称是否正确
- 检查类型是否存在于当前程序集中

#### 3. 服务解析失败
- 检查服务是否已注册
- 检查服务依赖是否已正确注册

#### 4. 性能问题
- 对于频繁解析的服务，建议使用 singleton 生命周期
- 对于大型应用，考虑使用批量注册

## 扩展与定制

### 扩展功能
1. **添加自定义生命周期**：在 `GetLifetime` 方法中添加新的生命周期类型
2. **添加自定义解析策略**：扩展 `ResolveServiceAsync` 方法，添加自定义解析逻辑
3. **添加新命令**：在 `Main` 方法中添加新的命令处理逻辑

### 定制配置
1. 修改 `ioc_aot.setting.json` 文件调整配置
2. 通过环境变量覆盖默认配置
