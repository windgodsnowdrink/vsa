# IP2Region 技能文档

## 概述

IP2Region 技能是一个基于 .NET 10 的高性能 IP 地址查询引擎，支持 AOT（Ahead-of-Time）编译，基于 IP2Region 库实现。该技能采用单文件执行模式，具有优异的性能和可靠性，能够快速准确地查询 IP 地址的地理位置信息。

## 核心功能

### 基本功能
- **IP 地址查询**：根据 IP 地址查询地理位置信息
- **详细信息查询**：获取 IP 地址的详细地理位置信息，包括国家、区域、省份、城市和 ISP
- **批量查询**：支持从文件中批量读取 IP 地址并进行查询
- **缓存机制**：使用内存缓存提高查询性能，减少重复查询
- **配置管理**：提供详细的配置选项，支持自定义数据库路径、缓存策略等
- **基准测试**：运行性能基准测试，评估查询性能

### 高级功能
- **多线程并发**：支持多线程并发处理批量查询，提高处理速度
- **错误处理**：完善的错误处理机制，确保查询过程稳定可靠
- **日志记录**：详细的日志记录，便于调试和监控
- **AOT 编译**：使用 Ahead-of-Time 编译提高性能和启动速度
- **单文件发布**：生成单个可执行文件，便于部署和使用

## 安装与配置

### 系统要求
- .NET 10 运行时
- Windows x64 操作系统
- IP2Region 数据库文件（可选）

### 安装方法
1. 确保已安装 .NET 10 运行时
2. 下载发布的单文件可执行程序
3. （可选）下载 IP2Region 数据库文件并放置在程序同一目录下，命名为 `ip2region.db`
4. 直接运行即可使用

### 配置选项
配置文件位于 `ip2region_aot.setting.json`，支持以下配置：

| 配置项 | 描述 | 默认值 |
|--------|------|--------|
| DbPath | IP2Region 数据库文件路径 | ip2region.db |
| CacheType | 缓存类型（none/memory/distributed） | memory |
| CacheExpirationMinutes | 缓存过期时间（分钟） | 30 |
| EnableLogging | 是否启用日志记录 | true |
| EnableBenchmarking | 是否启用基准测试 | true |
| BatchSize | 批量处理大小 | 1000 |
| ConcurrentThreads | 并发线程数 | 4 |

### 环境变量
可以通过环境变量覆盖默认配置：

| 环境变量 | 描述 |
|----------|------|
| IP2REGION_DB_PATH | IP2Region 数据库文件路径 |
| IP2REGION_CACHE_TYPE | 缓存类型 |
| IP2REGION_CACHE_EXPIRATION | 缓存过期时间（分钟） |
| IP2REGION_ENABLE_LOGGING | 是否启用日志记录 |
| IP2REGION_ENABLE_BENCHMARKING | 是否启用基准测试 |
| IP2REGION_BATCH_SIZE | 批量处理大小 |
| IP2REGION_CONCURRENT_THREADS | 并发线程数 |

## 使用方法

### 命令格式
```bash
ip2region_aot <command> [arguments]
```

### 命令列表

| 命令 | 别名 | 描述 | 参数 |
|------|------|------|------|
| search | s | 查询IP地址 | ip |
| info | i | 查询IP地址（详细信息） | ip |
| batch | b | 批量查询IP地址 | filePath [save] |
| config | co | 显示配置 | |
| benchmark | bm | 运行基准测试 | iterations |
| help | h, ? | 显示帮助信息 | |

### 示例

#### 1. 查询 IP 地址

```bash
ip2region_aot search 1.1.1.1
```

**预期输出**：
```

============================================================
查询IP: 1.1.1.1
查询结果: 澳大利亚|0|0|0|Cloudflare
查询用时: 12.345 ms
```

#### 2. 查询 IP 地址（详细信息）

```bash
ip2region_aot info 8.8.8.8
```

**预期输出**：
```

============================================================

国家: 美国
区域: 0
省份: 0
城市: 0
ISP: Google
查询用时: 5.678 ms
```

#### 3. 批量查询 IP 地址

```bash

# 然后运行批量查询
```

**预期输出**：

## 性能特性

### AOT 编译优势
- **启动速度快**：AOT 编译消除了 JIT 编译的开销，程序启动更快
- **内存占用低**：减少了运行时的内存使用，特别是对于大型应用
- **部署简单**：生成单个可执行文件，无需额外依赖
- **安全性高**：减少了运行时攻击面，提高了安全性

### 缓存机制
- **内存缓存**：使用内存缓存存储查询结果，减少重复查询的开销
- **缓存过期**：支持配置缓存过期时间，确保数据的及时性
- **缓存命中率**：通过基准测试可以查看缓存命中率，评估缓存效果

### 多线程并发
- **并发线程数**：可配置的并发线程数，根据系统性能进行调整
- **批处理大小**：可配置的批处理大小，优化处理效率
- **线程安全**：确保多线程环境下的线程安全

## 故障排除

### 常见问题

#### 1. 无法运行程序
- 检查是否已安装 .NET 10 运行时
- 检查操作系统是否为 Windows x64
- 检查程序文件是否完整

#### 2. 查询结果为"未知"
- 检查 IP2Region 数据库文件是否存在
- 检查数据库文件路径是否正确
- 检查 IP 地址格式是否正确

#### 3. 批量查询速度慢
- 调整 `ConcurrentThreads` 配置，增加并发线程数
- 调整 `BatchSize` 配置，优化批处理大小
- 确保系统有足够的内存和 CPU 资源

#### 4. 缓存不生效
- 检查 `CacheType` 配置是否为 "memory"
- 检查 `CacheExpirationMinutes` 配置是否合理
- 查看日志记录，确认缓存操作是否正常

### 日志记录
程序会在控制台输出日志信息，包括：
- 操作开始和完成的时间
- 处理状态和结果
- 错误信息和异常详情
- 数据库加载状态
